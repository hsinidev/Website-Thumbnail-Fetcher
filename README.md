## ✨ Overview

**doodax.com** is a state-of-the-art web application engineered to democratize access to visual web data. Built by **HSINI MOHAMED**, this platform allows developers, designers, and marketers to instantly visualize any URL on the internet through a high-performance interface.

The project features a mesmerizing, animated galaxy interface ("Nebula Engine") that provides an immersive user experience, coupled with a robust compliance framework including Privacy Policy, Terms of Service, and DMCA integration.

### 🌟 Key Features

-   **Instant Visualization**: Real-time simulation of website screenshots with configurable viewports.
-   **Immersive Cosmic UI**: A multi-layered, GPU-accelerated nebula and starfield background system.
-   **Comprehensive SEO**: Includes a massive, collapsible 3500-word SEO guide, full JSON-LD Schema markup, and optimized meta tags.
-   **Compliance Ready**: Built-in modal system for Privacy Policy, Terms, DMCA, and Guides tailored for doodax.com.
-   **Responsive & Accessible**: Flawless execution across mobile, tablet, and desktop devices.
-   **Secure Architecture**: Designed with security-first principles for API handling and data processing.

## ⚙️ Getting Started

### Prerequisites

-   Node.js (v18 or later recommended)
-   npm or yarn

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/hsinidev/website-thumbnail-fetcher.git
    cd website-thumbnail-fetcher
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm start
    ```

## 🔒 Security Note

This application is designed to be secure. API keys and sensitive credentials should strictly be handled via environment variables (`process.env`). Never commit real API keys to version control.
